# Política de privacidade — extensão Nexame

A extensão Nexame — sincronização TEC não coleta senhas, cookies, tokens de autenticação, enunciados ou comentários.

Ela lê somente estatísticas que já estão visíveis em páginas autenticadas do TEC, como cadernos, acertos, erros e resultados exibidos. Esses dados são mantidos temporariamente no armazenamento local do navegador (`chrome.storage.local`) e entregues à aplicação Nexame quando o painel é aberto.

Nenhum dado é enviado a servidores de terceiros pela extensão. O Nexame pode sincronizar os registros com o Supabase quando o usuário estiver autenticado na aplicação, conforme a política de privacidade do sistema.

O usuário pode remover os dados locais a qualquer momento pelo popup da extensão ou desinstalando-a. A extensão não vende dados nem usa informações para publicidade.
